# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 2.x | Yes |
| 1.x and older | No |

## Reporting a vulnerability

Do not open a public issue for a vulnerability, leaked webhook, bypass, denial-of-service vector, or privacy-sensitive log sample. Use GitHub’s **Report a vulnerability** flow under the repository Security tab.

Include the plugin version, Paper/Folia build, Java version, minimal reproduction, impact, and a redacted configuration. Never include a live Discord webhook URL or player private-message content.

You should receive acknowledgement within 72 hours. Fix timing depends on severity and reproducibility. A coordinated advisory and release will be prepared for confirmed issues.
